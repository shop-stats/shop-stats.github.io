Sign-in isn’t set up yet

Accounts use Supabase, a hosted service that keeps passwords and saved files secure. To turn it on:

  1. Create a free account at supabase.com and make a new project.
  2. In the project, open SQL Editor, paste the contents of supabase/setup.sql from this site’s folder and run it.
  3. Open Project Settings → API and copy the Project URL and the anon public key into js/config.js.
  4. Reload this page.

The README has the full steps, including email settings. The rest of the site works without accounts.
